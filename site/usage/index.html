How it's counted: each phone with "Count this phone in usage numbers" on (Settings › About, on by default) adds one to a public counter the first time it's used each day, week and month, once when first installed, once per version, and once per song it plays. It sends no ID, no song names and nothing about the person. Counting started with v0.3.6, and debug builds never count. The counters are kept by Abacus, a free service; daily counters fade after about five months without being read. This page isn't linked from the site.
