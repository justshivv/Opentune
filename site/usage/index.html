Unique download browsers by release

Requests through this website only, counted once per browser per release. Not completed downloads or installations.

New counts use random installation IDs and database deduplication. App updates keep an ID; reinstalling or clearing app data creates a new one. Browser downloads use a separate random ID; clearing storage or using another browser creates another ID. These measure installations and browsers, not unique people. Direct GitHub downloads, offline reports not yet uploaded, disabled usage sharing, and older app versions are not included in unique counts. No hardware IDs, account identities or song names are collected. Old Abacus counts cannot be converted to unique counts and are not mixed into these totals. This dashboard is public and displays aggregate totals only.
