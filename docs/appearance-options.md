# Fonts and player appearance

These options are local to each Android/TV installation and are not controlled by the remote dashboard.

- **Settings → Look and feel → Fonts & readability:** System sans (new default), Outfit, Serif, Monospace, and an imported font. Medium text is the default; Regular and Bold remain available. Headings and lyrics keep their stronger emphasis.
- **Import a font file:** choose a TrueType `.ttf` or OpenType `.otf` file, up to 8 MB. Android validates it before it becomes active. OpenTune copies it into private storage, so deleting the original document does not break the font. Replacing/removing it removes the old private copy. A missing restored file falls back to System sans.
- **Settings → Player → Player layout → Apple Music inspired:** edge-to-edge cover artwork, neutral surfaces, white controls and a quiet lyrics/queue background. Existing playback, lyrics, queue and song actions remain available.
- **Settings → Player → Player background → AMOLED black:** pure `#000000` behind the player, including lyrics. Mesh, glow, full-screen Canvas and edge-to-edge artwork are suppressed in this mode; the regular cover remains visible. Mini-player glass preferences stay independent.

Font and layout preferences persist with normal settings. Existing settings without the new font fields receive the readable defaults. Changing appearance does not affect audio decoding, add-on resolution or quality upgrades.
