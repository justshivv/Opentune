OpenTune 1.0.3 improves add-on compatibility and gives you more control over the player’s appearance.

- Fixes lossless add-ons returning “invalid source response” when their response omits codec metadata. Audio validation still checks the actual file before a lossless upgrade.
- Adds System sans, Outfit, Serif and Monospace fonts, selectable weights, and custom TTF/OTF font imports. The default is now easier to read.
- Adds an Apple Music inspired player layout and a true-black AMOLED player background. Mini-player glass remains available.
- Adds signed remote-configuration support for home sections, announcements, featured playlists, community links and admin add-on settings across Android/TV and the web player.
- Includes the latest changes from `claude/wizardly-sagan-8ge2ek`.

Find fonts in **Settings → Look and feel → Fonts & readability**, and the new player options under **Player layout** and **Player background**.

The remote-configuration dashboard requires a separate VPS installation; it is not activated by installing this APK. See [the administrator guide](https://github.com/justshivv/Opentune/blob/main/docs/remote-configuration.md). Existing settings continue to work until the dashboard is deployed. Personal add-ons and OpenTune-hosted source verification remain independent.

Install over the official app to keep your settings. Choose **arm64-v8a** for most recent phones or **universal** if unsure. The release uses the official signing identity; `SHA256SUMS.txt` contains APK checksums.
