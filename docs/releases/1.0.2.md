OpenTune 1.0.2 adds verified access to OpenTune-hosted lossless sources and fixes the verification errors seen in the preview.

- Supports OpenTune Monochrome, NetEase, Internet Archive and Musopen Classical sources.
- Fixes trust loading and signed-request checks that previously rejected the official app.
- Shows clearer verification, network and source-resolution errors.
- Adds approval of browser verification requests from the official Android app.
- Keeps public community add-ons independent of OpenTune verification.

Install this update over the official app or verification preview; it uses the same signing identity and a higher version code.

To add NetEase, paste this URL in Settings → Audio → Audio add-ons:
https://opentune-lossless-addon.create-a-new-site-with-sites.workers.dev/netease/manifest.json

OpenTune-hosted sources require a supported device with hardware verification and a locked bootloader. Public third-party sources remain available without that verification. Audio availability and original resolution depend on the upstream recording; no 96/192 kHz tier is guaranteed.

Choose **arm64-v8a** for most recent phones, including Galaxy S25 Ultra, or **universal** if unsure. SHA256SUMS.txt contains the APK checksums.
